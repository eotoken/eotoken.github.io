# EO Token Whitepaper — GitHub Pages

Official bilingual public whitepaper website for EO Token.

- Website: https://eotoken.github.io/
- Default language: English
- Korean: https://eotoken.github.io/ko/
- Version: Public Release v1.0
- Website UI: v1.1 bilingual edition
- Network: Solana
- Token: EO

## Language structure

- `/` — English homepage
- `/whitepaper/` — English whitepaper
- `/ko/` — Korean homepage
- `/ko/whitepaper/` — Korean whitepaper
- `/downloads/` — English and Korean official PDFs

## Deployment

This repository is configured for GitHub Pages via GitHub Actions. Push to `main`; the existing Pages workflow publishes the repository root.

## Source of truth

The website is a web-readable presentation of EO Token Whitepaper v1.0 Public Release. The Korean Public Release remains the source text for the English rendering until a separately announced English legal review is completed.
