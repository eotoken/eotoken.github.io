# EO Token Whitepaper — GitHub Pages

Official public whitepaper website for EO Token.

- Website: https://eotoken.github.io/
- Version: Public Release v1.0
- Website UI patch: v1.0.1
- Language: Korean (English planned)
- Network: Solana
- Token: EO

## Deployment

This repository is configured for GitHub Pages via GitHub Actions.

1. Push to `main`.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **GitHub Actions**.
4. The `Deploy EO Token Whitepaper to GitHub Pages` workflow publishes the repository root.

## Source of truth

The website is a web-readable presentation of the official EO Token Whitepaper v1.0 Public Release. For formal distribution and archival use, refer to the PDF in `/downloads`.
